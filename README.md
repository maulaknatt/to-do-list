# To-Do List V2 - Premium TypeScript Edition

Modern migration of the To-Do List application built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**.

## ✨ Features
- **Modern Tech Stack**: Next.js, React, TypeScript.
- **Premium UI**: Dark mode glassmorphism, smooth animations, and responsive layout.
- **Ready for Vercel**: Optimized for seamless deployment.

## 🚀 Getting Started

1. **Enter the folder**:
   ```bash
   cd v2
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## ☁️ Deployment to Vercel

1. Push this folder (or the whole project) to **GitHub**.
2. Connect your repository to **Vercel**.
3. Set the Root Directory to `v2`.
4. Deploy!
